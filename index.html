DEMO / 01 Build from a rough idea

Turn intent into a working first version

Give Codex a clear outcome, the important constraints, and a way to verify the result—then refine from something real.

Starter prompt

Inspect this project and build a small, polished first version of [idea]. Preserve existing work. Before you finish, test the main user path and tell me what remains as a placeholder.

Open the recreation guide +
  1. 01
    Define the finish line.

    Name one user, one useful outcome, and one testable main path.

  2. 02
    Let Codex inspect first.

    Ask it to understand the current project before proposing changes.

  3. 03
    Review the first version.

    React to what is visible: hierarchy, missing states, tone, and friction.

  4. 04
    Verify, then keep moving.

    Run the relevant checks and record what still needs real content.

DEMO / 02 Improve through feedback

Turn “it feels off” into useful direction

Use evidence and concrete reactions to guide a second pass without prescribing every implementation detail.

Starter prompt

The page works, but the hierarchy feels flat and the next action is unclear. Review it at mobile and desktop sizes, improve the visual rhythm and interaction states, and keep the current content and functionality intact.

Open the recreation guide +
  1. 01
    Name the reaction.

    Describe what feels slow, unclear, crowded, or visually weak.

  2. 02
    Protect what already works.

    State which content, behavior, and decisions must remain intact.

  3. 03
    Ask for comparison.

    Have Codex summarize meaningful before-and-after changes.

  4. 04
    Check edge cases.

    Review keyboard use, reduced motion, narrow screens, and empty states.

Keep in mind

Useful, not infallible.

01

Inspect the output

AI can make plausible mistakes. Read the changes and test the path that matters.

02

Protect sensitive data

Do not paste secrets, credentials, or private participant information into prompts.

03

Work in small loops

A visible first pass gives you better feedback than one enormous, over-specified request.
